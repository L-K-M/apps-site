# Directory preview

`npm run test:e2e` writes viewport and full-page desktop/mobile captures to
`test-results/`. `directory.png` is the desktop viewport used by the README.
Refresh it from `test-results/preview-desktop.png` after layout changes.

Mac-app image sources, sample data and reviewed file hashes are recorded in
[`macos-screenshots.json`](macos-screenshots.json). Reproduction instructions are in
[`catalogue/assets/README.md`](../catalogue/assets/README.md).

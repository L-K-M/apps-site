# Platform icons

`platforms.svg` bundles ten symbols from [Bootstrap Icons 1.13.1](https://github.com/twbs/icons/tree/ce0e49dd063243118a115f17ad1fe1fe7576d552/icons).
The original paths use a 16 × 16 view box; symbols are named by platform id.

| Platform | Upstream icon |
|---|---|
| macOS | `apple.svg` |
| Windows | `windows.svg` |
| Linux | `tux.svg` |
| Android | `android.svg` |
| iOS | `phone.svg` |
| Web | `globe.svg` |
| Firefox | `browser-firefox.svg` |
| Chrome | `browser-chrome.svg` |
| Pebble | `smartwatch.svg` |
| RG Nano | `controller.svg` |

Icons retain Bootstrap's MIT license in `LICENSE-bootstrap.txt`, independent of
the application's Unlicense. The generator copies the sprite and license into
the site. Each use supplies a platform name for assistive technology and a hover
title. No script, icon font, or remote service is needed.
